How it works

    

      

        
1

        
Extraction happens in your browser

        
Your .pptx, .pdf, and .docx files are parsed locally with JavaScript the moment you drop them in — nothing is uploaded anywhere at this step.

      

      

        
2

        
Your key talks directly to OpenAI

        
The extracted text (plus the reformatting rulebook) is sent straight from your browser to OpenAI's API using your own key. No server of ours ever sees your files or your key.

      

      

        
3

        
You get one HTML study guide

        
The result is a single self-contained HTML file — tabs, decision trees, or comparison cards depending on your course type — ready to open, download, or study from immediately.

      

    

    

      This is a static site with no backend. It cannot see your API key or your files — they never pass through any server we control.
      Standard OpenAI API usage charges from your own account apply per reformat.
